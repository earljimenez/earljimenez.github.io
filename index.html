What I've built

Client and employer code stays private, so these describe what I built and why it mattered.

01

Enterprise Playwright framework for four business applications

Owned test automation for a construction contract and project-valuation platform, a financial aid and grant management system, a document data-entry tool and an insurance policyholder portal.

  • More than 1,000 automated tests on a Page Object Model framework with reusable components, fixtures and centralized test data: about 830 for the contract platform, 220 regression and release tests for the financial aid system, 160 BDD scenarios (Playwright + Cucumber) for the insurance customer portal, and 80 end-to-end and API tests for the document data-entry tool.
  • Typed API clients for the checks a UI can't prove, such as role-based permissions and concurrency conflicts.
  • Runs in Azure DevOps pipelines across development, test, release and production environments.

AI-assisted QA toolkit

Value-level report validation

Financial reports checked figure by figure, not just "does the page load".

04

Faster, more readable pipeline runs

Made a growing end-to-end suite quicker to run and easier to read when it fails.

  • Sharded Playwright runs across parallel pipeline agents, then merged the results into one HTML report across shards and stages.
  • Added a step decorator to page-object methods so every report reads as plain business steps.
  • Stabilized flaky tests after a major Angular upgrade and removed redundant trace uploads from the pipeline.
  • Added access-control coverage for route guards that must deny unauthorized users.
